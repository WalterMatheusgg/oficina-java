## Sobre

Este repositório reúne exercícios e projetos desenvolvidos durante meus estudos de Java e back-end. As APIs Pulso e Conta Clara exploram problemas diferentes: operações bancárias persistidas e um assistente de orçamento que interpreta comandos de voz com confirmação antes de registrar despesas.

## Projetos

| Projeto | O que você encontra |
|---|---|
| [Conta Clara API](conta-clara-api/) | Assistente de orçamento por voz com Spring AI, rascunhos confirmáveis, resumo mensal e limites por categoria |
| [Pulso Banking API](design-patterns-bank-api/) | API bancária com PostgreSQL, idempotência, histórico transacional e padrões Strategy, Facade e Repository |
| [Desafio.java](Desafio.java) | Calculadora com menu Swing: temperatura, salários, área, volume, energia e combustível |
| [ListarArquivos.java](ListarArquivos.java) | Listagem de arquivos e ordenação por data de modificação |
| [Person.java](Person.java) | Coleta de alturas, contagens e médias usando JOptionPane |
| [jogoRio.java](jogoRio.java) | Desafio de lógica da travessia de lobo, ovelha e repolho |
| [Index.java](Index.java) | Exercício simples de repetição |

## Executar

Tenha um JDK instalado. Para executar um dos exercícios na raiz:

```bash
git clone https://github.com/WalterMatheusgg/oficina-java.git
cd oficina-java
javac jogoRio.java
java jogoRio
```

As instruções para executar cada API estão no README de sua pasta:

- [Conta Clara API](conta-clara-api/README.md)
- [Pulso Banking API](design-patterns-bank-api/README.md)
